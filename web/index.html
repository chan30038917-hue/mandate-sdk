The problem

AI agents need to pay for services autonomously. But giving them a private key means a bug or hack can drain the entire account. Manual approval defeats the purpose of autonomy.

The solution

Mandate SDK lets the owner sign a mandate with their passkey that defines spending limits. The agent pays only within those limits.

🔐

Passkey-signed

Owner signs with WebAuthn. No private key exposed.

⛓️

On-chain verified

P256 precompile validates every payment on Monad.

🚫

No custody

The contract never holds funds. Payments go directly.

Install in 30 seconds

npm install github:chan30038917-hue/mandate-sdk

Then use it in 10 lines:

import { MandateSDK } from "mandate-sdk";

const sdk = new MandateSDK({ privateKey: process.env.PRIVATE_KEY });

// Owner signs a mandate (once)
const { mandateId, passkey } = await sdk.registerMandate({
  maxPerTx: "1",
  maxPerPeriod: "10",
});

// Agent pays autonomously
const result = await sdk.pay({
  mandateId,
  passkey,
  amount: "0.5",
  recipient: "0x...",
});
