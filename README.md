# Mandate SDK

SDK para mandatos de pago verificables con passkey en Monad.

## Que es esto

Permite a agentes autonomos pagar por servicios sin exponer las claves privadas del usuario. El dueño firma un mandato con su passkey que define limites de gasto, y el agente paga solo, dentro de esos limites, con verificacion on-chain.
